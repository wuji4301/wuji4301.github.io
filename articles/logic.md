
# 命题
中学中的许多命题都可以写出*若p则q*的形式
# 充分条件和必要条件
| 命题的真假 | 推出关系 | 条件 |
| --- | --- | --- |
| *若p则q*为真命题 | p$\Rightarrow$q | p 是 q 的充分条件， q 是 p 的必要条件 |
| *若p则q*为假命题 | p$\not\Rightarrow$q | p 不是 q 的充分条件， q 不是 p 的必要条件 |
## 如何理解“充分”“必要”
### 充分
“充”是充足、装满；“分”是分量、份额。合起来就是“分量给够了”

也就是“p”的所有条件全部充足，马上就可以推出“q”了
### 必要
“必”是必定、一定；“要”是需要、需求。合起来就是“必定需要”、“少不了”

也就是只有“p”满足，那么“q”就必须出现
# 充要条件
字面意思，充分且必要条件

如果p是q的充要条件，那么有：$p\Rightarrow q 且 q\Rightarrow p$

显然此时q也是p的充要条件

所以充要条件是成对出现的

只有$p\Leftrightarrow q$才会出现充要条件，称为*p与q互为充要条件*
# 全称量词与存在量词
$\forall$

全称量词，对于任意的

$\exists$
存在量词，存在
